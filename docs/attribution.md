# Authorship and source attribution

The supplied technical report identifies Xinying (Ashley) Liu, University of California, San Diego, as its author. This public repository organizes the supplied ECE 285 project scripts, report, historical result summaries, and original figure assets.

The report is a course technical report using a NeurIPS-style template. The template does not indicate conference acceptance or publication. `neurips_2025.sty` is preserved with its upstream author comments; no ownership of that style file is claimed.

Chest radiographs are from Paul Mooney's Kaggle distribution of the Chest X-Ray Images (Pneumonia) dataset: https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia . The report figure's real reference row retains that dataset provenance. The full dataset is not redistributed. Consult its source for dataset attribution and reuse terms.

The public architecture diagram and comparison plots were constructed from the supplied implementations and recorded values. They are explanatory figures, not new experiments or new medical images. Source scripts remain unchanged except where an explicitly documented maintenance fix is needed.

The current primary report is `ECE_285_HW1.pdf`, titled *Anatomical Structure versus Generative Fidelity: A Hierarchical VAE Study of Chest Radiographs*. Its Figures 2 and 3 supply the training plot, posterior reconstructions, and independent prior samples used in this revision. The earlier report and LaTeX remain separate historical artifacts.
